# NiZZioN Homebrew Tap

```sh
brew install --cask nizzion/tap/notchhider
```

| Cask | App |
|---|---|
| `notchhider` | [Notch Hider](https://github.com/NiZZioN/NotchHider): hides the MacBook notch with a true-black or blurred-glass menu bar strip |

Casks are updated automatically from each app's latest GitHub release (see `.github/workflows/update.yml`).
